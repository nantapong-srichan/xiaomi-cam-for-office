# Office Camera

A cross-platform desktop application for viewing multiple Xiaomi C400 camera feeds in one simple interface.

The application uses C# and Avalonia for the desktop UI, LibVLCSharp for video playback, and go2rtc as a local streaming gateway. Xiaomi authentication stays in go2rtc; the application only consumes the resulting camera streams.

## Features

- View two camera feeds side by side
- Select and start each camera independently or start both together
- Play HLS streams produced by go2rtc
- Run on macOS, Windows, and Linux with .NET 8
- Keep Xiaomi credentials and tokens outside the application source

## Architecture

```text
Xiaomi C400 cameras
        ↓
      go2rtc
        ↓ HLS
  Office Camera desktop app
```

## Requirements

- .NET 8 SDK
- go2rtc 1.9.15 or newer
- A Xiaomi account with the cameras already added in Mi Home/Xiaomi Home
- Network access between the computer running go2rtc and the cameras

## Setup

1. Download the go2rtc binary for your operating system.
2. Start go2rtc from the directory containing your private `go2rtc.yaml`:

   ```sh
   ./go2rtc
   ```

3. In the go2rtc Web UI at `http://127.0.0.1:1984`, add the Xiaomi account and load the cameras.
4. Configure two stream names in the private config, for example:

   ```yaml
   streams:
     classroom: "xiaomi://ACCOUNT:sg@CAMERA_IP?did=DEVICE_ID&model=MODEL_ID"
     livingroom: "xiaomi://ACCOUNT:sg@CAMERA_IP?did=DEVICE_ID&model=MODEL_ID"
   ```

   Replace all placeholders with values generated by go2rtc. Never publish this file.

5. Start the application:

   ```sh
   dotnet restore
   dotnet run
   ```

The application expects the streams to be available at:

```text
http://127.0.0.1:1984/api/stream.m3u8?src=classroom
http://127.0.0.1:1984/api/stream.m3u8?src=livingroom
```

## Remote or shared use

For multiple users, run one go2rtc instance on an always-on office computer and point each application instance to that gateway. Use a private VPN or other authenticated network access for remote users. Do not expose the go2rtc API directly to the public internet.

## Security

`go2rtc.yaml` is intentionally ignored by Git because it contains Xiaomi authentication tokens and camera connection details. Do not commit it, its backups, or copied tokens into source code, screenshots, logs, or issue reports.
